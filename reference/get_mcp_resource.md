# Get an MCP resource from a list of resource definitions (convenience function)

Get an MCP resource from a list of resource definitions (convenience
function)

## Usage

``` r
get_mcp_resource(resource_defs, resource_uri)
```

## Arguments

- resource_defs:

  List. A list of resource definitions

- resource_uri:

  Character. The URI of the resource to get

## Value

The resource definition
